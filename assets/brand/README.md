# Brand assets

The ikas App UI mark is the ikas Builders symbol (a bolt interlocked with a "B") on a rounded tile. The registry, previews and docs all live on builders.ikas.com, so the kit uses the same symbol.

Every file here is generated by `pnpm brand:build` (`scripts/build-brand.mjs`). Don't edit them by hand. Change the geometry in the script and regenerate.

## Which file to use

| File | Use it for |
| --- | --- |
| `logo.svg` | Places that theme through CSS variables, like the shadcn registry directory. Tile is `var(--foreground)`, mark is `var(--background)`. |
| `logo-black.svg` / `logo-white.svg` | Fixed-color logo at 32px and up: README, docs headers, slides. |
| `logo-*-small.svg` | Same logo with wider cuts, for 16–24px (favicons, tabs, dense UI). |
| `mark.svg` | The symbol without the tile, `currentColor`. Next to a wordmark or inside your own container. |
| `png/logo-{black,white}-{16…1024}.png` | Raster sizes: 16/24 use the small master; 180 is the Apple touch icon; 192/512 cover web manifests. |
| `favicon.ico` | 16, 32 and 48px in one file. |
| `social-preview.png` | GitHub repository social preview (Settings → General → Social preview), 1280×640. |
| `directory-entry.json` | The entry for `apps/v4/registry/directory.json` in shadcn-ui/ui, with `logo` already inlined. |

## Rules

- One color per surface: black tile with white mark, or the reverse. No gradients, shadows or brand-color tiles.
- Keep clear space of at least 25% of the tile width around the logo.
- Below 32px use the `-small` variant.
- Don't redraw, rotate, recolor parts of, or add effects to the symbol.
- The MIT license of this repo does not cover the ikas name or logo.

## Geometry

The symbol was traced from the ikas Builders logo (`ikas-builders/public/ikas-light-logo.png`). Once the brand team shares the original vector, replace the paths in `geometry()` and rerun `pnpm brand:build`.
