`WheelPicker`, `WheelPickerGroup` and `DateWheelPicker` take a `sound` prop: a soft tick as each row crosses the band while the user drags, flicks, scrolls or steps the wheel. Off by default, silent when the value changes from outside, one shared audio context for the page. Every date wheel picker demo has an on/off toggle for it.
