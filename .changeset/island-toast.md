Add `@ikas/island-toast`: a dynamic-island toast stack. `IslandToaster` mounts once and `island()` / `island.success|info|warning|error|loading|promise|dismiss` work from anywhere, like `toast()`. Each toast is a 36px pill; one with a description or action opens itself after 150ms and folds 1.5s before it leaves. New toasts go to the front and fold the older ones behind (up to `visibleToasts`, 8px apart, each smaller and fainter); hover or focus opens the stack as a list and pauses every timer, as does a hidden tab. Swipe toward the edge (40px or a 0.11px/ms flick), the close button or Esc dismisses. `tone` is `dark` (opaque ink in both themes) or `light` (white in both themes); `position` takes six edges, the bottom ones growing upward. Motion: a layout morph between fixed sizes (inline radius, content counter-scaled) on springs with bounce per transition, more for the smaller target; the content swaps one state for the next with `mode="wait"` and a 4px blur; text uses tabular numbers. It enters from beyond the edge by its own height and leaves the same way on SPRING_EXIT. A swipe tracks the finger 1:1 toward the edge and fades with the distance, rubber-bands the other way, pauses the timers while held and springs back with a little bounce; buttons never start a swipe, and the close button has a 44px hit area. Reduced motion keeps the swipe and crossfades everything else. Errors and warnings are announced assertively, the rest politely. One demo, `island-toast/basic`: a stack on first paint, the statuses, a promise, an action, three in a row, and tone (which also switches the page theme) and position switches.

`@ikas/theme`: new `--island` / `--island-foreground` tokens (`bg-island`), and a `.light` scope with the light values so a subtree can stay light inside a dark page.

`@ikas/motion`: `ISLAND_SPRING` (`enter`, `open`, `fold`, `stack`, `release`), the only bouncing springs, for the island toast.
